過去問_v04

GitHub Pages用の完成版です。
このフォルダ内のファイルをそのままリポジトリへアップロードしてください。

主な改修内容
・「今日の学習」を２１問に固定
・①〜⑮の分野から偏りにくく自動抽出
・直近３０問の再出題を抑制
・同一テーマの重複を抑制
・同じテーマが連続しにくい出題順に変更
・４択はＳＳ問題レベルを維持
・正解を必ず含め、同系統の紛らわしい選択肢から３つを自動抽出
・選択肢の表示順を毎回シャッフル
・学習履歴はブラウザ内に保存

アップロード方法
１　このZIPを解凍
２　中身のファイルをGitHubの対象リポジトリへアップロード
３　GitHub Pagesで main / root を指定
